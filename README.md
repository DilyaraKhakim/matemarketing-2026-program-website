# ММ’26 — мобильная программа

Открыть `index.html` в браузере. В одном файле встроены оформление, логика и все 92 события из предоставленной выгрузки LMS. Установка и интернет для просмотра программы не нужны.

Основной мобильный вид — компактные карточки с круглыми портретами спикеров, объединённые по времени начала. Портреты также используются в виде с краткими описаниями: фотографии найдены для 78 событий, у совместных выступлений показаны все доступные портреты. Карточки без фотографии не используют обрезанный постер вместо лица. Для длинных выступлений есть раскрывающийся список «В это время ещё идут». Сравнение включается для блока времени; на обычной карточке остаётся действие «Пойду». Большие постеры и сортировка доступны через «Вид и порядок», заметки и список записей — через подробности.

Поиск; фильтры по залу, спикеру, теме, длительности и времени начала; сортировка; список с краткими описаниями; сравнение двух выступлений; личный маршрут с интервалами и сменой залов; список для просмотра записей; заметки; экспорт выбранных выступлений в календарь ICS. Состояние локального файла и сайта GitHub Pages хранится отдельно; сохранение зависит от разрешений браузера.

В разделе «Пойду» есть переключатель «Доклады / Мой план дня»: план показывает выбранные доклады по времени с перерывами, пересечениями и сменой залов. «К времени» открывает слоты текущего дня с учётом фильтров. После удаления или переноса доклада между списками можно отменить последнее изменение; сообщение остаётся до закрытия или следующего удаления. Отмена возвращает прежнее состояние обоих списков.

Треки взяты из таблицы организаторов. Список записей не обещает их доступность. Интервалы плана вычислены по расписанию и не учитывают время ходьбы между залами.

После прокрутки к докладам сверху появляется компактная строка: время текущей группы слева, дата справа (например, «26.11»). Дата открывает выбор дня; для 17 ноября показано «онлайн». В плане дня строка следует за текущим докладом. Сравнение остаётся в обычных заголовках групп.

Короткие предлоги при отображении связываются со следующим словом неразрывным пробелом. Обрабатываются текстовые узлы, включая диалоги; исходные данные, значения полей и заметок, ссылки и экспорт календаря не изменяются.

Официальные постеры из сохранённых ресурсов встроены в HTML и доступны в подробностях без интернета. Из-за изображений размер файла около 25 МБ.

## Данные

- `program_6.csv`: даты, начало и конец, названия, залы.
- `program_6.md`: имена спикеров, краткие и полные описания.
- `Матемаркетинг_17_11.html`, `Матемаркетинг_26_11.html`, `Матемаркетинг_27_11.html`: сохранённые страницы каждого дня. Сопоставлены все 90 карточек, у 82 событий есть дополнительные сведения о спикерах. Время и залы совпали с CSV.
- `IMPORT_REPORT.json`: полнота импорта и отсутствующие сведения.

17 ноября — 15 событий, 26 ноября — 39, 27 ноября — 38. Все записи экспорта перенесены, включая незаполненную тему. Это сохранённый снимок LMS, а не автоматически обновляемое расписание.

В HTML нет отдельных карточек для «ЗДЕСЬ БУДЕТ ЕЩЕ ОДНА ТЕМА» и «Т-Банк 100к1: аналитика против интуиции». Эти две записи сохранены по CSV/Markdown; отсутствие в сохранённом HTML не трактуется как отмена.

## Разработка

Логика редактируется в `app.js`, `enhancements.js` и `mobile.js`, дополнительные стили — в `enhancements.css`, затем встраиваются в HTML импортёром. Для повторного импорта нужны Python и BeautifulSoup4 (`bs4`, если используется сохранённая HTML-страница).

Фильтр компаний использует явно названные организации в сведениях о спикерах, с объединением вариантов написания. Треки из Excel организаторов доступны отдельным компактным выбором над докладами. Сопоставлены 75 событий с 11 треками. Для 15 онлайн-докладов, незаполненной темы и доклада «Семь кругов LLM-разработки…» подтверждённого трека в таблице нет. Поиск по авторским тематическим категориям убран из окна фильтров.

`import_tracks.py` использует заголовки колонок соответствующего раздела Excel. Время и залы не импортируются из Excel и остаются из LMS. Точные совпадения и проверенные переименования с адресами исходных ячеек записаны в `TRACK_IMPORT_REPORT.json`. Для повторного импорта требуется также `openpyxl`.

```text
python build_site.py
node verify_program.cjs
```

Эти команды обновляют код и оформление, сохраняя встроенные данные и изображения. Для полного повторного импорта данных используется `python import_program.py`; ему дополнительно нужны исходные сохранённые HTML со всеми ресурсами и Excel организаторов.

Для импорта портретов нужен Pillow. Команда `python import_program.py --download-portraits` скачивает фотографии по ссылкам спикеров из сохранённых страниц LMS в локальную папку `speaker_photos` и пересобирает сайт. Последующие импорты используют этот кеш без сети. В HTML встраиваются уменьшенные версии WebP до 160 × 160 px; исходные фотографии в Git не включаются.
